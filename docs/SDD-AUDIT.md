# Audit SDD vs kode (RF-4)

Tanggal audit: 2 November 2026. Kode: branch `main` di `9948d45`. Dokumen: `docs/SDD.md` (ekspor
Claude Doc, sinkron RF-3). Audit ini hanya membaca. Kode, config, dan `docs/SDD.md` tidak diubah.
Revisi SDD dikerjakan pemilik proyek di Claude Doc.

Cara membaca:

- Nomor baris SDD merujuk ke `docs/SDD.md` di commit ini. Bukti kode ditulis `file:baris`.
- **[KEPUTUSAN]** berarti temuan itu butuh keputusan pemilik proyek (atau pembimbing). Usulan
  teksnya hanya salah satu pilihan, bukan keputusan.
- Di luar cakupan dan tidak diperiksa: isi eval RAG Tahap 1, KB, prompt (termasuk
  `rag.prompt_variant`, `rag.source_priority`, `llm.prompt_variants`, dan batas 120 kata di
  prompt), gerbang (`rag.gate.threshold`), serta `vision.imgsz` dan hal lain di cv/imgsz.
- Bukti perintah: `python -m mica check` (config prod) dijalankan sekali saat audit; kamera tidak
  dibuka dan Groq tidak dipanggil.
