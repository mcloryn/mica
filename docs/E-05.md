# E-05: evaluasi STT (protokol perekaman dan perintah)

Dokumen kerja untuk E-05 (`audio.stt.backend`, `audio.vad.*`, `audio.max_utterance_s`,
`audio.stt.no_speech_threshold`). Angka yang belum disepakati ditulis TBD.

## Aturan keputusan E-05 (disalin dari SDD 2.4, tidak diubah)

> Aturan E-05 ditetapkan sebelum data: syarat p95 waktu sampai transkripsi tampil paling lama 3 detik di laptop kiosk; pemenang WER terkecil; seri dimenangkan STT lokal. Kandidat: faster-whisper lokal, variasi thread, Groq Whisper, dan varian petunjuk kosakata PMB (hotwords/initial\_prompt). Metrik tambahan: CER, Recall@5 retrieval atas transkripsi, dan laju transkripsi palsu pada rekaman diam dan bising.

`python -m mica.eval stt` hanya mencetak tabel menurut aturan ini; pemenang tidak dipilih
otomatis. Syarat p95 hanya sah bila diukur di laptop kiosk.

## Protokol perekaman relawan

- Jumlah penutur: TBD, disepakati dengan pembimbing.
- Jumlah kalimat per penutur: TBD, disepakati dengan pembimbing. Kalimat diambil dari
  pertanyaan `answerable` set dev (`data/eval/questions.jsonl`), sehingga `qid` bisa diisi untuk
  cek Recall@5.
- Setiap penutur juga merekam rekaman `diam` (tidak bicara) dan `bising` (bunyi ruangan tanpa
  pertanyaan). Jumlah dan durasinya TBD.
- Rekam di ruangan dan dengan mikrofon yang sama dengan kiosk bila memungkinkan; catat
  perangkat dan ruangan di catatan run.
- Format file: WAV 16 kHz, mono, 16-bit. `eval stt` menolak format lain (tidak ada resample
  diam-diam).
- Penutur ditulis sebagai kode anonim (P01, P02, ...). Nama, NIM, dan data pribadi lain tidak
  pernah ditulis di manifest, nama file, atau hasil.
- Rekaman disimpan hanya di laptop dev, di `data/eval/speech/<nama>/`. Folder ini ada di
  `.gitignore`, jadi rekaman tidak pernah di-commit; hanya `data/eval/speech/contoh/manifest.jsonl`
  (tanpa audio) yang ada di repo.

## Formulir persetujuan (isi minimal)

Setiap relawan menandatangani persetujuan tertulis sebelum direkam. Isinya:

1. Tujuan: suara direkam untuk mengukur ketepatan pengenalan ucapan MICA (kiosk informasi PMB
   Universitas Mikroskil) dalam skripsi S-1; tidak dipakai untuk tujuan lain.
2. Yang direkam: relawan membacakan beberapa pertanyaan PMB yang sudah disiapkan, serta beberapa
   detik diam atau bunyi ruangan. Tidak ada pertanyaan pribadi.
3. Penyimpanan: rekaman disimpan hanya di laptop pengembang, tidak diunggah ke repositori atau
   layanan awan. Bila backend Groq diuji, rekaman dikirim ke layanan Groq untuk ditranskripsi;
   relawan diberi tahu dan boleh menolak bagian ini.
4. Identitas: relawan hanya dicatat sebagai kode anonim; hasil yang dilaporkan berupa angka
   gabungan.
5. Penghapusan: rekaman dihapus setelah skripsi selesai (setelah sidang dan revisi). Relawan
   boleh meminta rekamannya dihapus kapan saja sebelum itu.
6. Sukarela: relawan boleh berhenti kapan saja tanpa konsekuensi.

Baris manifest hanya boleh dibuat untuk rekaman dengan persetujuan; `persetujuan` harus `true`,
dan manifest dengan satu baris tanpa persetujuan ditolak seluruhnya.

## Format manifest

`data/eval/speech/<nama>/manifest.jsonl`, satu objek JSON per baris:

| Field | Wajib | Isi |
| --- | --- | --- |
| `id` | ya | ID unik rekaman, mis. `p01-q01` |
| `file` | ya | WAV 16 kHz mono, relatif terhadap folder manifest |
| `jenis` | ya | `pertanyaan`, `diam`, atau `bising` |
| `referensi` | untuk `pertanyaan` | Teks yang dibacakan |
| `qid` | tidak | qid set dev, untuk Recall@5 transkripsi vs referensi |
| `penutur` | ya | Kode anonim |
| `persetujuan` | ya | Harus `true` |

Contoh: `data/eval/speech/contoh/manifest.jsonl`.

## Perintah

Semua perintah hanya jalan di mode dev. Nilai VAD dan penyaring masih TBD, jadi diberikan lewat
CLI sebagai nilai coba dan dicetak sebagai nilai coba:

```
python -m mica.eval stt --config config/dev.yaml --dataset data/eval/speech/<nama>/manifest.jsonl \
    --vad-threshold 0.5 --min-silence-ms 500 --max-utterance-s 15 \
    --min-speech-ms 250 --no-speech-threshold 0.6
```

Varian kandidat:

- variasi thread: `--threads 2,4` (satu konfigurasi per nilai);
- petunjuk kosakata: `--hotwords <file>` (satu istilah per baris, diteruskan ke parameter
  `hotwords` faster-whisper 1.2.1);
- Groq Whisper: `--backend groq --groq-model whisper-large-v3-turbo` atau `whisper-large-v3`
  (butuh `GROQ_API_KEY` di `.env`; audio keluar dari laptop, hanya untuk relawan yang setuju).

Hasil di `results/E-05/<run>/`: `summary.csv` (satu baris per konfigurasi) dan per konfigurasi
`per_item.csv` (tanpa audio; hipotesis disamarkan dengan scrub_pii) serta `run.json` (versi
paket, revisi model, thread, nilai coba, CPU, AC/baterai, SHA-256 manifest dan rekaman).

Metrik per rekaman: WER dan CER (normalisasi pilot: normalize_for_speech, huruf kecil, tanpa
tanda baca), audio_s, stt_s, waktu sampai teks (akhir bicara sampai VAD menutup ucapan, ditambah
stt_s), transkripsi palsu (diam/bising: 1 bila ada transkripsi), filtered_by, dan hit@5
retriever aktif untuk transkripsi dan referensi bila `qid` ada.

Uji asap tanpa mikrofon (data sintetis Piper, bukan hasil E-05):

```
python scripts/e05_smoke_synthetic.py
```

## Amandemen 1 (18 Okt 2026, sebelum data E-05)

Ditetapkan sebelum data E-05 dikumpulkan. Alasannya keputusan desain pengguna 18 Okt 2026:
input suara menjadi push-to-talk (`audio.input_mode: push_to_talk`; Langkah 42). Aturan
keputusan E-05 dari SDD 2.4 tidak diubah.

- Rekaman uji tetap dari manifest (protokol dan format di atas tidak berubah). Audio yang sama
  masuk ke STT yang sama, jadi WER, CER, Recall@5, dan stt_s tidak berubah karena push-to-talk.
- Setiap rekaman diperlakukan sebagai satu kali tombol ditahan. VAD (pysilero-vad,
  `audio.vad.threshold`) hanya mengecek ada ucapan dan memangkas hening di awal/akhir.
- Laju transkripsi palsu kini diukur pada rekaman push-to-talk tanpa ucapan (`diam` dan
  `bising`). Bila cek VAD tidak menemukan ucapan, STT tidak dipanggil dan rekaman dihitung
  tanpa transkripsi palsu. Bila VAD menemukan ucapan, STT dipanggil dan hasilnya dihitung
  seperti semula.
- "Waktu sampai teks" = tombol dilepas (akhir rekaman) sampai teks tersedia = lama cek VAD +
  stt_s.
- Parameter yang tidak lagi relevan untuk menentukan akhir ucapan di mode push-to-talk:
  - `audio.vad.min_silence_ms` hanya dipakai mode `vad` (perbandingan);
  - anggaran deteksi akhir ucapan 0,5 detik tidak berlaku.
  Tetap relevan: `audio.vad.threshold` (cek ucapan dan pemangkasan), `audio.vad.min_speech_ms`
  (penyaring ucapan terlalu pendek), `audio.stt.no_speech_threshold`, dan
  `audio.max_utterance_s` (batas rekaman; tercapai = dikirim otomatis).
