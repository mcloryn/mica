# Folder dokumen bersih

Taruh di sini dokumen Mikroskil yang sudah dirapikan, satu file per topik, misalnya:

- `biaya.md`
- `pendaftaran.md`
- `prodi-teknik-informatika.md`
- `beasiswa.md`

Di baris pertama tiap file, tulis sumber dan tanggal pengambilan, contoh:
`Sumber: brosur PMB 2026, diambil 2026-10-15`

File PDF atau halaman web asli taruh dulu di folder `data/raw/`.
