`<nama>/images/`, `<nama>/labels/` (YOLO), `<nama>/manifest.jsonl`, serta `colors.csv` dan
`colors_rater2.csv` untuk E-08. Format, persetujuan, dan aturan privasi: `docs/E-07.md` dan
`docs/E-08.md`.

Isi folder ini tidak pernah di-commit (`.gitignore`), hanya ada di laptop dev, ditolak di mode
kiosk, dan dihapus setelah skripsi selesai.
